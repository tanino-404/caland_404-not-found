# CALAND

## 予定の混み具合マップ — 毎日が、村になる。

1か月のカレンダーを島に見立て、各日には予定の数だけマイクラ風ブロックが積み上がり、頂上にはその日の予定（美容室・飲食・仕事・結婚式…）を模したボクセルの建物が並ぶ。予定の多い日ほど高い山になり、その上に小さな町ができる。家計簿やフィットネスなど「管理プラグイン」の目標を達成した月は、島そのものが黄金郷・マッチョの島・知識の島に変わる。

- **タイトルとログイン**：CALAND のロゴと回る飾り島。画面をクリックして ID とパスワードでログイン（新規登録も可）。島が組み上がるローディングのあと、今日の月の島へ
- **月ビュー（3D）**：7 列 × 週数のカレンダーを斜め上から俯瞰。ドラッグで回転、ホイールでズーム。左右の「◀」「▶」で前後の月へ（隣の月の島は先に建っていて、横にスライドする）。日をホバーすると日付と件数、クリックで日ビューへ
- **日ビュー（3D）**：カメラがその日の頂上へ降りて町を拡大。右のパネルに予定一覧。「月に戻る」で俯瞰へ
- **年ビュー（3D）**：下部バー「年カレンダー」で雲を抜けて、12 か月の島を 4 × 3 に並べた海へ。島をホバーすると件数と、その月に目標を達成したプラグインの ★。クリックでその月へ
- **自分の島と友達の島**：自分の島には自分が持ち主の予定だけが建つ。下部バー「友達の島へ移動」で友達の島を見に行ける（見るだけ）。ふたりの予定がある日は、ハートの旗を曳く飛行機が飛ぶ
- **予定の共有**：日ビューから予定を「建てる」（相手を「誘う」と 2 人の共有予定）、他の人の予定に「参加する」、自分の予定を「削除」（共有なら「抜ける」）。ホバーすると屋上の建物の足元に持ち主の色の台座が出る（共有は縦縞）
- **管理プラグイン**：下部バー「管理機能」から家計簿・NISA・フィットネス・自主勉強・釣り・ペット・自炊・ゲームの練習を選ぶ。選んだプラグインが「表示中」になり、その目標の達成で島の見た目が決まる（家計簿・NISA → 黄金郷、フィットネス → マッチョの島、自主勉強 → 知識の島。ほかは空や海に絵が出る）。プラグインは `plugins/<id>/plugin.json` を書くだけで増やせる（書式は `plugins/README.md`）
- **天気と時刻**：今の天気（YuMake）と端末の時計で、雨・雪・雲・雷と、昼・夕方・夜の光が 3D に出る。設定のデバッグモードで手で切り替えられる
- **BGM と効果音**：場面ごとに曲が変わる。音量は設定で変える
- **持ち物**：日ビューで場所（OpenStreetMap 上の名称。例：大阪城）を入れて予定を建てると、その場所の天気から持ち物を提案し、LINE に送る


## 技術スタック

Vite 8 / React 19 / TypeScript / three.js / @react-three/fiber / @react-three/drei。家計と予定のサーバーは Python 3.11 の標準ライブラリ（`http.server` + `sqlite3`）。詳細は `docs/architecture/architecture.md`。

持ち物の提案と画面の天気だけ、この PC のサーバーが外部 API を呼ぶ。使っている API と用途は、末尾の「[使用している API・外部サービス](#使用している-api外部サービス)」にまとめた。

## 必要環境

- Node.js **20.19 以上**（22.12 以上推奨）。`node -v` で確認
- npm 10 以上
- Python **3.11**
- WebGL が動くブラウザ（Chrome / Edge / Safari の最新版）
- 持ち物を LINE に送るとき・実際の天気を出すときだけ、ネットワークと `secret/.env` のキー

## インストール

```bash
git clone <このリポジトリの URL>
cd tcp_osaka_2026_404human_not_found/src
npm install
```

`src/` が Vite プロジェクトのルートです（`package.json` はここにあります）。ライブラリの追加はチームに声をかけてから行ってください。サーバーは追加パッケージを入れません。`server/.venv` が無いときだけ、次で作ります。

```bash
cd server
python3.11 -m venv .venv
```

## 秘密情報（持ち物を送るとき・天気を出すとき）

`secret/.env.template` を `secret/.env` にコピーして値を入れる。

| 名前 | 内容 |
| --- | --- |
| `CLAUDE_API_KEY` | Anthropic の API キー |
| `CLAUDE_MODEL` | 空なら `claude-sonnet-5` |
| `YUMAKE_API_KEY` | YuMake 気象情報 API のキー（持ち物と画面の天気） |
| `LINE_CHANNEL_ACCESS_TOKEN` | Messaging API のチャネルアクセストークン（長期） |
| `LINE_PUSH_TO` | 送信先の LINE ユーザー ID（`U` で始まる 33 文字）。コンソールの「チャネル基本設定 > あなたのユーザーID」 |
| `WEATHER_LAT` / `WEATHER_LON` | 画面の天気演出に使う地点（10 進の緯度・経度）。空なら大阪城 |

送信先の LINE アカウントで、公式アカウントを友だち追加しておく。

## 起動方法

サーバーと画面の両方を動かす。

```bash
cd server
source .venv/bin/activate
python app.py
```

`http://127.0.0.1:8787` と出る。別の端末で画面を起動する。

```bash
cd src
npm run dev
```

ブラウザで `http://localhost:5173/` を開く。`/api` は、画面を出している PC の中で 8787 へ渡る。タイトル画面が出るので、画面をクリックして ID `たろう`・パスワード `1234` でログインする（「新規登録」で新しいアカウントも作れる。新しいアカウントはまっさらな島から始まる）。ローディングのあと、**今日の月** の 3D 月ビューが出る。BGM はブラウザの制限で最初のクリックから鳴る。

同じ Wi-Fi の人は、`npm run dev` が表示する Network の URL を開く。サーバー自体は 127.0.0.1 のまま。

保存データを消してサンプルに戻したいときは、下部バー「設定」の「保存したデータを消してサンプルに戻す」を押す（タイトル画面に戻る）。以前の版で作った `server/data/ledger.sqlite` は、起動時に新しい形（パスワード・プラグイン形式の家計簿）へ移し替えられる。デモの前には一度サンプルに戻しておくとよい。

ポートを固定したい場合：`npm run dev -- --port 5173 --strictPort`

## 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | カメラ回転 |
| ホイール / ピンチ | ズーム |
| 画面左右の「◀」「▶」 | 月ビューでは前後の月（12 月の次は翌年 1 月）、年ビューでは前後の年 |
| 日のタワーをホバー | 建物が浮いて足元に持ち主の色の台座、下中央に日付・件数・持ち主別の内訳 |
| 日のタワーをクリック | 日ビューへ降りる |
| 参加する（日ビュー） | 他の人の予定に自分も加わる → 台座が 2 色になる |
| 建てる（日ビュー） | タイトルと種類を入れて自分の予定を追加 → 塔が 1 段伸びる。「誘う」にチェックすると相手のカレンダーにも同じ予定が入る。場所を入れると持ち物を提案して LINE に送る |
| 持ち物を提案（日ビュー） | 場所が入っている予定について、提案と LINE 送信をもう一度行う |
| 削除 / 抜ける（日ビュー） | 自分の予定を消す。共有の予定なら自分だけ抜けて相手の予定として残る |
| ◀ 月に戻る | 月ビューへ |
| 下部バー「年カレンダー」/「月カレンダー」 | 雲を挟んで年ビューと月ビューを切り替える |
| 年ビューの島をクリック | その月の島へ |
| 下部バー「友達の島へ移動」 | 行き先を選んで友達の島へ（見るだけ）。友達の島からは「自分の島に戻る」 |
| 下部バー「管理機能」 | プラグインを選ぶと「表示中」になり、島の見た目がそのプラグインの達成で決まる。右に入力パネル（記録・目標・月送り）。まだ自分のグループが無いプラグインは「○○を始める」で作る |
| 下部バー「設定」 | 名前、BGM / 効果音の音量、天気と時刻のデバッグモード、サンプルに戻す |
| 下部バー「ログアウト」 | タイトル画面へ |

```
/
├─ agent_rule.md            ← AI エージェント共通ルール（唯一の正）
├─ original_rule/           ← 追加ルール
├─ docs/
│   ├─ human_idea/          ← コンセプト（人間のみ編集）
│   ├─ architecture/        ← 技術スタック・画面構成・src 構造
│   ├─ agent_docs/          ← AI の作業メモ（git 管理外）
│   └─ conversation_log/    ← セッションごとの会話ログ（git 管理外）
├─ plugins/                 ← 管理プラグイン（1 フォルダ = 1 プラグイン。書式は plugins/README.md）
├─ server/                  ← 予定・管理プラグイン・天気・持ち物のサーバー（Python 3.11）
│   ├─ app.py               ← http://127.0.0.1:8787
│   ├─ .venv/               ← 仮想環境（git 管理外）
│   └─ data/ledger.sqlite   ← この PC のデータベース（git 管理外）
├─ src/                     ← アプリ本体（Vite プロジェクトルート）
│   ├─ index.html
│   ├─ package.json
│   └─ src/                 ← React / three.js のソース
├─ config/                  ← アプリ設定のサンプル（秘密情報は置かない）
└─ secret/.env.template     ← 持ち物提案・天気用の環境変数サンプル
```


## 使用している API・外部サービス

ヒーローズ・リーグ 2026 の[素材・API 一覧](https://heroes-league.net/2026/#/materials)に載っているものを使っている。名前と URL は一覧のとおり。

| API（一覧での名前） | 使っている場所 | 用途 |
| --- | --- | --- |
| [LINE Messaging API](https://protopedia.net/material/349) | アプリ（`server/suggest.py`） | 日ビューで場所つきの予定を建てると、持ち物の提案を LINE に push で送る |
| [YuMake気象情報API 体感温度予報](https://protopedia.net/material/2200) | アプリ（`server/suggest.py`、`server/weather.py`） | 予定の場所の天気・体感温度（WBGT・不快指数など）から持ち物を決める。画面の雨・雪・雲・雷の演出も、同じ API の現在時刻に近い予報で決める |
| [OverPass API](https://protopedia.net/material/934) | アプリ（`server/suggest.py`） | 予定に入れた場所名（例：大阪城）を OpenStreetMap から検索し、緯度経度と施設の種類（タグ）を得る。これで天気を取る地点と持ち物の判断材料が決まる |
| [Vonage](https://protopedia.net/material/1313)（SMS API） | 開発運用（`.github/workflows/pr-summary-sms.yml`） | PR に付いた CodeRabbit の要約を、運営者の携帯に SMS で通知する。 |
| [AIコードレビュー（CodeRabbit）](https://protopedia.net/material/2050) | 開発運用（GitHub の PR） | 公認プラグイン（`plugins/<id>/`）を申請する場合の PR をレビューし、要約を付ける。 この要約結果をVonageで運営元へ通知する。 |

- 一覧の対象外：持ち物と LINE の本文を作るために、Anthropic の Claude API も使用（`CLAUDE_API_KEY`）。
