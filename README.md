# tcp_osaka_2026_404human_not_found

チーム「404human_not_found」の [Tech Challenge Party OSAKA 2026](https://tech-challenge-party.connpass.com/event/398681/) 用リポジトリ。この作品を [ヒーローズ・リーグ 2026](https://heroes-league.net/) のオンラインリーグへ出す。

## 予定の混み具合マップ — 毎日が、村になる。

お題「カレンダーの予定を山や谷の地形として立体的に見る」への回答。
1 か月のカレンダーを島に見立て、各日には予定の数だけマイクラ風ブロックが積み上がり、頂上にはその日の予定（美容室・飲食・仕事・結婚式…）を模したボクセルの建物が並ぶ。予定の多い日ほど高い山になり、その上に小さな町ができる。貯金が月の目標を超えた月は黄金郷になる。

- **月ビュー（3D）**：7 列 × 週数のカレンダーを斜め上から俯瞰。ドラッグで回転、ホイールでズーム。日をホバーすると日付と件数、クリックで日ビューへ
- **日ビュー（3D）**：カメラがその日の頂上へ降りて町を拡大。右のパネルに予定一覧。「月に戻る」で俯瞰へ
- **年ビュー（2D）**：12 か月を「島カード」で並べ、各月のミニマップを表示。色は 3D と同じ「標高」スケール（海 → 土 → 石 → 雪）。島をクリックでその月の 3D へ。目標を達成した月は金の枠
- **みんなで 1 つの地図**：ユーザー名だけでログインし、メンバー全員の予定が同じ島に建つ。日をホバーすると、屋上の建物の足元に持ち主の色の台座が出る（2 人で共有する予定は 2 色の縦縞）。日ビューから自分の予定を「建てる」（相手を「誘う」と 2 人の共有予定になる）、他の人の予定に「参加する」、自分の予定を「削除」（共有なら「抜ける」）ができる
- **ふたりの島**：右上のボタンで並べ方を切り替える。手前に自分の島、海の向こうに相方の島。ふたりの予定がある日は、塔と塔の間をハートの旗を曳く飛行機が往復する
- **家計簿**：右上「家計簿」から収入・支出と月の目標を入れる。貯金が目標以上の月は黄金郷
- **持ち物**：日ビューで場所（OpenStreetMap 上の名称。例：大阪城）を入れて予定を建てると、その場所の天気から持ち物を提案し、LINE に送る

予定・メンバー・家計は、サーバーを動かしている PC の SQLite（`server/data/ledger.sqlite`）に入る。ログイン中の名前だけ、そのブラウザの localStorage に残る。空のデータベースは起動時に、2026 年一年分のサンプル（メンバー「たろう」「はなこ」）で埋まる。

## 技術スタック

Vite 8 / React 19 / TypeScript / three.js / @react-three/fiber / @react-three/drei。家計と予定のサーバーは Python 3.11 の標準ライブラリ（`http.server` + `sqlite3`）。詳細は `docs/architecture/architecture.md`。

持ち物の提案だけ、この PC のサーバーが次の順で外部 API を呼ぶ。キーはブラウザに出さない。

1. [Overpass API](https://wiki.openstreetmap.org/wiki/JA:Overpass_API) で場所名から緯度経度を取る
2. [YuMake 体感温度予報](https://api.yumake.jp/) で降水量・風・気温・湿度・気圧・雲量と、体感温度・WBGT・不快指数・風冷指数を取る（発表時刻から最大 78 時間先）
3. Claude API が持ち物の案を作り、天気の数値と照合してから LINE の本文を書く
4. [LINE Messaging API](https://developers.line.biz/ja/docs/messaging-api/getting-started/) でその本文を送る

## 必要環境

- Node.js **20.19 以上**（22.12 以上推奨）。`node -v` で確認
- npm 10 以上
- Python **3.11**
- WebGL が動くブラウザ（Chrome / Edge / Safari の最新版）
- 持ち物を LINE に送るときだけ、ネットワークと `secret/.env` のキー

## インストール

```bash
git clone <このリポジトリの URL>
cd tcp_osaka_2026_404human_not_found/src
npm install
```

`src/` が Vite プロジェクトのルートです（`package.json` はここにあります）。ライブラリの追加はチームに声をかけてから行ってください。サーバーは追加パッケージを入れません。`server/.venv` が無いときだけ、次で作ります。

```bash
cd server
python3.11 -m venv .venv
```

## 秘密情報（持ち物を送るとき）

`secret/.env.template` を `secret/.env` にコピーして値を入れる。`.env` は git に入れない。

| 名前 | 内容 |
| --- | --- |
| `CLAUDE_API_KEY` | Anthropic の API キー |
| `CLAUDE_MODEL` | 空なら `claude-sonnet-5` |
| `YUMAKE_API_KEY` | YuMake 気象情報 API のキー |
| `LINE_CHANNEL_ACCESS_TOKEN` | Messaging API のチャネルアクセストークン（長期） |
| `LINE_PUSH_TO` | 送信先の LINE ユーザー ID（`U` で始まる 33 文字）。コンソールの「チャネル基本設定 > あなたのユーザーID」 |

送信先の LINE アカウントで、作った公式アカウントを友だち追加しておく。追加していない相手には届かない。

## 起動方法

サーバーと画面の両方を動かす。

```bash
cd server
source .venv/bin/activate
python app.py
```

`http://127.0.0.1:8787` と出る。別の端末で画面を起動する。

```bash
cd src
npm run dev
```

ブラウザで `http://localhost:5173/` を開く。`/api` は、画面を出している PC の中で 8787 へ渡る。最初にログイン画面が出るので「たろう として入る」か「はなこ として入る」を押す（新しい名前を入力して参加することもできる）。その奥に、予定が最も多い月（3 月）の 3D 月ビューが出る。3 月は黄金郷。

同じ Wi-Fi の人は、`npm run dev` が表示する Network の URL を開く。家計 API 自体は 127.0.0.1 のまま。

保存データを消してサンプルに戻したいときは、ログイン画面の「保存したデータを消してサンプルに戻す」を押す（ログアウト → ログイン画面）。

ポートを固定したい場合：`npm run dev -- --port 5173 --strictPort`

## デモ手順

1. 「たろう として入る」でログイン。**3 月の黄金郷** を見せる。「ブロックの数が予定の数。貯金が目標を超えた月は黄金郷になります」
2. 高い日にマウスを乗せる → 建物の足元に色が出る。「ピンクがたろう、青がはなこ。2 色の縞は 2 人の予定」
3. 右上「一年を見る」→ **12 月** の島をクリック → **19 日** をクリック。カメラが降りて、教会の周りに花びらが舞う。右パネルで はなこ の予定に「参加する」→ 台座が 2 色になる
4. 「◀ 月に戻る」→ 左下の月送りで、8 月（ほとんど海）と 3 月・12 月（高い島）の違いを見せる
5. **今日から 3 日以内** の日を開く。予定名を入れ、場所に「大阪城」と入れて「建てる」。数十秒後、右パネルに持ち物と、LINE に送った本文が出る。スマホの LINE にも届く。場所は OpenStreetMap 上の名称にする。雨でない日に折りたたみ傘は出ない

場所の検索で Overpass が混雑していると、同じ検索を 2 秒、4 秒、8 秒待って最大 4 回やり直す。4 回とも失敗したときは、そのエラーが画面にそのまま出る。

## 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | カメラ回転 |
| ホイール / ピンチ | ズーム |
| 日のタワーをホバー | 建物が浮いて足元に持ち主の色の台座、下中央に日付・件数・持ち主別の内訳 |
| 日のタワーをクリック | 日ビューへ降りる |
| ふたりの島で見る / ひとつの島で見る（右上） | 島の並べ方を切り替える。「ふたりの島」は手前に自分、奥に相方の島。ふたりの予定の日は飛行機が行き来する |
| 家計簿（右上） | その月の収入・支出・目標。達成すると島が黄金郷になる |
| 参加する（日ビュー） | 他の人の予定に自分も加わる → 台座が 2 色になる |
| 建てる（日ビュー） | タイトルと種類を入れて自分の予定を追加 → 塔が 1 段伸びる。「誘う」にチェックすると相手のカレンダーにも同じ予定が入る。場所を入れると持ち物を提案して LINE に送る |
| 持ち物を提案（日ビュー） | 場所が入っている予定について、提案と LINE 送信をもう一度行う |
| 削除 / 抜ける（日ビュー） | 自分の予定を消す。共有の予定なら自分だけ抜けて相手の予定として残る |
| ◀ 月に戻る | 月ビューへ |
| ログアウト（右上） | ログイン画面へ。別の名前で入り直すと同じ地図を別の人として見られる |
| ◀ N月 / N月 ▶ | 前後の月へ（年内で循環） |
| 一年を見る | 年ヒートマップへ |
| ヒートマップの月 | その月の 3D へ |
