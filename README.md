# tcp_osaka_2026_404human_not_found

チーム「404human_not_found」の [Tech Challenge Party OSAKA 2026](https://tech-challenge-party.connpass.com/event/398681/) 用リポジトリ。

## 予定の混み具合マップ — 毎日が、村になる。

お題「カレンダーの予定を山や谷の地形として立体的に見る」への回答。
1 か月のカレンダーを島に見立て、各日には予定の数だけマイクラ風ブロックが積み上がり、頂上にはその日の予定（美容室・飲食・仕事・結婚式…）を模したボクセルの建物が並ぶ。予定の多い日ほど高い山になり、その上に小さな町ができる。

- **月ビュー（3D）**：7 列 × 週数のカレンダーを斜め上から俯瞰。ドラッグで回転、ホイールでズーム。日をホバーすると日付と件数、クリックで日ビューへ
- **日ビュー（3D）**：カメラがその日の頂上へ降りて町を拡大。右のパネルに予定一覧。「月に戻る」で俯瞰へ
- **年ビュー（2D）**：一年分を 53 週 × 7 曜日のヒートマップで表示。色は 3D と同じ「標高」スケール（草 → 土 → 石 → 雪）。月名や日をクリックでその月の 3D へ
- **みんなで 1 つの地図**：ユーザー名だけでログインし、メンバー全員の予定が同じ島に建つ。日をホバーすると、屋上の建物の足元に持ち主の色の台座が出る（2 人で共有する予定は 2 色の縦縞）。日ビューから自分の予定を「建てる」（相手を「誘う」と 2 人の共有予定になる）、他の人の予定に「参加する」、自分の予定を「削除」（共有なら「抜ける」）ができる

予定データは `src/src/data/sampleEvents.ts` の固定サンプル（2026 年一年分、メンバー「たろう」「はなこ」）を初期値とし、ログイン・追加・参加の結果はブラウザの localStorage に保存される。サーバー・外部 API・パスワード・秘密情報は不要。

## 技術スタック

Vite 8 / React 19 / TypeScript / three.js / @react-three/fiber / @react-three/drei。バックエンドなし。詳細は `docs/architecture/architecture.md`。

## 必要環境

- Node.js **20.19 以上**（22.12 以上推奨）。`node -v` で確認
- npm 10 以上
- WebGL が動くブラウザ（Chrome / Edge / Safari の最新版）

## インストール

```bash
git clone <このリポジトリの URL>
cd tcp_osaka_2026_404human_not_found/src
npm install
```

`src/` が Vite プロジェクトのルートです（`package.json` はここにあります）。ライブラリの追加はチームに声をかけてから行ってください。

## 起動方法

```bash
cd src
npm run dev
```

ブラウザで `http://localhost:5173/` を開く。最初にログイン画面が出るので「たろう として入る」か「はなこ として入る」を押す（新しい名前を入力して参加することもできる）。その奥に、予定が最も多い月（12 月）の 3D 月ビューが表示されている。

保存データを消してサンプルに戻したいときは、ログイン画面の「保存したデータを消してサンプルに戻す」を押す（ログアウト → ログイン画面）。

ポートを固定したい場合：`npm run dev -- --port 5173 --strictPort`

## デモ手順（30 秒）

1. 「たろう として入る」でログイン。**12 月の島** を見せる。「ブロックの数が予定の数。高い山の上に町ができています」
2. 雪をかぶった **19 日** にマウスを乗せる → 建物の足元に色が出る。「ピンクがたろう、青がはなこ。2 色の縞は 2 人の予定＝結婚式」
3. クリック → カメラが降りて、教会の周りに花びらが舞う「結婚式の日の町」。右パネルで はなこ の予定に「参加する」→ 台座が 2 色になる。フォームで予定名を入れ、種類を選び、「誘う：はなこ」にチェックして「建てる」→ 2 人の予定として塔が 1 段伸び、足元の台座は 2 色
4. 「◀ 月に戻る」→ 左下の「◀ 11月」「1月 ▶」で月を切り替え、山と谷の違いを見せる（8 月は草原、3 月・12 月は雪山）
5. 右上「一年を見る」→ 一年のヒートマップ。「上から見ると、ふたりの一年はこんな地形でした」

## 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | カメラ回転 |
| ホイール / ピンチ | ズーム |
| 日のタワーをホバー | 建物が浮いて足元に持ち主の色の台座、下中央に日付・件数・持ち主別の内訳 |
| 日のタワーをクリック | 日ビューへ降りる |
| 参加する（日ビュー） | 他の人の予定に自分も加わる → 台座が 2 色になる |
| 建てる（日ビュー） | タイトルと種類を入れて自分の予定を追加 → 塔が 1 段伸びる。「誘う」にチェックすると相手のカレンダーにも同じ予定が入る |
| 削除 / 抜ける（日ビュー） | 自分の予定を消す。共有の予定なら自分だけ抜けて相手の予定として残る |
| ◀ 月に戻る | 月ビューへ |
| ログアウト（右上） | ログイン画面へ。別の名前で入り直すと同じ地図を別の人として見られる |
| ◀ N月 / N月 ▶ | 前後の月へ（年内で循環） |
| 一年を見る | 年ヒートマップへ |
| ヒートマップの月名・セル | その月の 3D へ |
