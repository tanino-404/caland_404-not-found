# アーキテクチャ設計（architecture.md の記入）

## やったこと

- `docs/human_idea/concept.md`（予定の混み具合マップ／マイクラ風 3D）をもとに `docs/architecture/architecture.md` を記入した。
  - 技術スタック：フロントのみ、Vite 8 + React 19 + TypeScript、three.js + @react-three/fiber v9 + @react-three/drei。3D モデルは外部アセットを使わず `boxGeometry` のボクセルをコード生成。2D ヒートマップは CSS Grid。外部 API・秘密情報なし。
  - 画面構成：`year`（2D ヒートマップ）→ `month`（3D 月俯瞰）→ `day`（同一シーンでカメラ補間ズーム）。`App` の `ViewState` で切替、ルーティングなし。
  - データモデル：`CalendarEvent` / `EventCategory`（8 種）/ `ViewState`。
  - 3D 表現の規約（座標系、ブロック質感、建物サイズ 0.3、3×3 屋上配置、ライト、fog）。
  - 固定データ方針：`src/src/data/sampleEvents.ts` に一年分。繁忙月・閑散月を意図的に作る。
  - `src/` 構造案と、コンフリクト回避のための並列作業単位 A〜D。
- 公式ドキュメント確認：Vite Getting Started（Node 20.19+ 要件、`react-ts` テンプレート）、React Three Fiber Installation（fiber v9 は React 19 とペア）。
- `npm view` で最新版を確認：vite 8.3.0 / react 19.3.0 / three 0.186.0 / @react-three/fiber 9.7.0 / @react-three/drei 10.7.8。
- 使ったスキル：なし（設計のみ。実装時に `frontend-design` / `vercel-react-best-practices` を読む）。
