# MVP 構築（src/ の初期化から 3 ビュー実装まで）

## やったこと

- `src/` を Vite 8 `react-ts` テンプレートで初期化し、three / @react-three/fiber / @react-three/drei / @types/three を追加。
  - `npm create vite@latest src` は `src/` に `.gitkeep` があるため非対話モードでキャンセルされた。テンプレートを別ディレクトリに生成して `src/` にコピーした（`.gitkeep` は残している）。
  - `@react-three/fiber@9.7.0` の peer 条件が `react >=19 <19.3` で、テンプレート既定の `^19.2.8` が 19.3.0 を解決して ERESOLVE になった。`--legacy-peer-deps` は使わず、`react@~19.2.8` / `react-dom@~19.2.8` に固定して解決。
  - `package.json` の name を `schedule-terrain-map` に変更。テンプレートの `App.css` / `index.css` / `assets/` / `public/icons.svg` / `src/README.md` を削除。
- 実装（`docs/architecture/architecture.md` の構造どおり）：
  - `types/calendar.ts`：`CalendarEvent` / `EventCategory`（8 種）/ `ViewState` / `CATEGORY_INFO`（表示名・色）。
  - `lib/calendar.ts`：月グリッド計算・日別集計・最繁忙月・日付表記。`lib/camera.ts`：座標変換とカメラ姿勢。`lib/pixelFont.ts`：3×5 ピクセルフォント。
  - `data/sampleEvents.ts`：固定データ。シード固定の乱数で 2026 年一年分（634 件）を決定的に生成。繁忙月 3・10・12 月、閑散月 8 月。見せ場の日（12/19 結婚式 9 件、3/27 仕事 8 件、10/10 旅行 7 件、6/6）を固定。
  - `components/models/`：`Voxel`（最小単位）、`materials.ts`（色→材質キャッシュ）、`blocks/Block.tsx`（草 / 土 / 石 / 雪の 6 面材質）、`blocks/blockKinds.ts`（高さ→種別、ヒートマップ標高色）、`objects/` に建物 8 種（美容室・飲食・オフィス・教会・病院・ジム・飛行機・学校）と対応表。
  - `components/month/`：`MonthScene`（Canvas・ライト・海面・fog・OrbitControls）、`DayTower`（地面 + 予定数ぶんのブロック + 屋上 3×3 の建物 + ハイライト + 出現アニメ）、`PixelLabels`（InstancedMesh 1 描画で日付文字）、`WeekdayHeader`（木の看板 SUN〜SAT）、`CameraRig`（pose 変化時に指数補間、到着後はユーザー操作に任せる）。
  - `components/hud/`：`MonthHud`（巨大な月数字、前後月、一年を見る、凡例、ホバーの日付ツールチップ）、`DayHud`（日付・予定一覧・月に戻る・10 件以上の超過表示）。
  - `components/year/YearHeatmap.tsx`：53 週 × 7 曜日の CSS Grid、月名ボタン、標高凡例。セル幅は `--heat-cell` で画面幅に追従。
  - `App.tsx`：`ViewState`（year / month / day）で切替。初期表示は最繁忙月。
  - `styles/global.css`：デザイントークン（インク #1b2a41 / 紙 #fff8e7 / 金 #ffc83d / 空グラデーション）、看板風パネル・ボタン、レスポンシブ、reduced-motion。
  - `index.html`：日本語タイトル、DotGothic16（Google Fonts）読み込み。
- 動作確認で見つけた調整：月俯瞰カメラが近く上段の週が切れていたため、`monthCameraPose` を引いて俯瞰角を上げた。年ヒートマップが狭い画面で横スクロールになるためセル幅を `clamp()` にした。
- `docs/architecture/architecture.md` の技術スタック・画面構成・3D 規約・`src/` 構造を実装に合わせて最新化。
- `README.md` を人間の指示により更新（概要・必要環境・インストール・起動・確認/ビルド・デモ手順・操作・フォルダ構成）。
- 使ったスキル：`frontend-design`（HUD とヒートマップの配色・書体・レイアウト決定）、`vercel-react-best-practices`（モジュール定数化・派生値の render 中計算・材質キャッシュ）。

## 動作確認（実行コマンドと結果）

- `cd src && npx tsc --noEmit -p tsconfig.app.json` → エラーなし。
- `cd src && npm run lint`（oxlint） → エラー・警告なし。
- `cd src && npm run build` → 成功（`dist/assets/index-*.js` 1,120 kB / gzip 308 kB。500 kB 超のチャンク警告は three.js 本体由来で想定内）。
- `cd src && npm run dev -- --port 5173 --strictPort` → Cursor 内蔵ブラウザで `http://localhost:5173/` を確認：
  - 12 月の 3D 月ビューが表示され、雪頂上のタワー（9 日・19 日）、草原の日、木の看板、前面のピクセル日付が描画される。
  - 19 日をクリック → カメラが頂上へ降り、右パネルに 9 件の予定（結婚式・美容室・飲食・旅行）が一覧表示される。
  - 「月に戻る」「◀ 11月 / 1月 ▶」「一年を見る」が動作し、年ヒートマップ（全 634 件）が表示される。
  - `vite-error-overlay` なし、DotGothic16 の読み込み成功（`document.fonts.check`）。
- 確認中に人間もブラウザを操作していた（pointer イベントを記録して切り分け済み。アプリのバグではない）。

## 未完了・懸念

- ホバー時のツールチップとハイライトは、ツールでホバーを再現できないため目視未確認（コードパスは単純）。
- DotGothic16 は Google Fonts から読み込むため、オフラインではシステムフォントに置き換わる（表示崩れはしないが世界観が薄れる）。デモ会場でオフラインの可能性があるなら、フォントファイルを `src/public/` に置く対応が必要。
- 月ビューの既定カメラでは、手前の高いタワーが奥の低いタワーの日付を隠すことがある（ドラッグで回転すれば見える）。
- `concept.md` の「あれば嬉しい機能」（アカウント共有、カレンダーインポート、建物のリッチ演出）は未着手。
- Node 20.19.0 は Vite 8 の下限ちょうど。問題は出ていないが、余裕があれば 22 系へ。
- dev サーバーはこのセッションでバックグラウンド起動したまま（ポート 5173）。不要なら停止する。
