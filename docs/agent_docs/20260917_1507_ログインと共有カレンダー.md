# ログインと共有カレンダー（あれば嬉しい機能 1）

## やったこと

- 予定に所有者を追加：`CalendarEvent.owners: string[]`（1 人以上。2 人以上なら共有の予定）。
- サンプルデータ：メンバー「たろう」「はなこ」を `SAMPLE_MEMBERS` に定義。結婚式は必ず 2 人で共有、それ以外は 12% で共有、残りはどちらか 1 人（`pickOwners`）。乱数消費が変わったため件数が 634 → 641 に変化。
- 状態と永続化：
  - `lib/storage.ts`：localStorage の 1 キー `schedule-terrain-map` に `{ version, members, currentUser, events }` を保存。バージョン不一致は捨ててサンプルから作り直す。不正な JSON は例外を投げる（握りつぶさない）。
  - `hooks/useSharedCalendar.ts`：`login` / `logout` / `addEvent` / `joinEvent` / `resetToSample`。保存は各アクションの中で行う（effect での保存はしない）。未ログインでの追加・空タイトル・未知の予定 ID は例外。
- メンバー色：`lib/members.ts`（`MEMBER_PALETTE` を登録順に割り当て、`ownerChipBackground` で共有予定は縦縞、`breakdownByOwner` で所有者別件数）。
- 3D の「縁取り」：`components/models/OwnerPlate.tsx`。ホバー / 選択中のタワーでは屋上の各建物が台座ぶん浮き、足元に所有者色の台座が出る。台座の厚み `PLATE_HEIGHT` は当初 0.05 だったが、15:26 の指示で立体感を減らすため 1/3（0.05 / 3 ≒ 0.017）にした。共有予定は人数ぶんの縦縞に分割。タワー全体の金色ハイライトは opacity 0.32 → 0.16 に下げて台座を見やすくした。
- HUD：
  - `LoginScreen.tsx`：ユーザー名だけのログイン。既存メンバーはワンクリック、新しい名前は入力。「保存したデータを消してサンプルに戻す」。3D を背景に重ねる。
  - `MonthHud.tsx`：右上に現在のユーザー（色チップ）とログアウト。凡例にメンバー色と「みんなの予定」。ツールチップに所有者別の内訳（例：たろう 3 · はなこ 4 · みんな 2）。
  - `DayHud.tsx`：各予定に所有者チップ（共有は 2 色）と所有者名、自分の予定でないものに「参加する」。下部に「（自分）の予定を建てる」フォーム（タイトル・種類）。カテゴリ値は型ガードで検証し、未知なら例外。
- `App.tsx`：`useSharedCalendar` から状態を受け取り、未ログインなら `LoginScreen` を表示。`byDate` は events から `useMemo` で派生。
- CSS：`.input` / `.link-btn` / `.btn-small` / `.btn:disabled` / ログイン画面 / ユーザーバッジ / ツールチップ内訳 / 日パネルのフォーム。
- `architecture.md`（技術スタック・画面構成 4 節・データモデル・src 構造・分担 E）、`README.md`（機能・起動・デモ手順・操作表）を更新。
- 使ったスキル：`frontend-design`（ログイン画面とフォームの語彙を既存の看板 UI に揃えた）、`vercel-react-best-practices`（`rerender-move-effect-to-event`：保存はイベントハンドラ内、`client-localstorage-schema`：version 付きキー）。

## 追記（15:21〜）：誘う・削除・種類チップ

- `useSharedCalendar.ts`：
  - `NewEventInput.invited: string[]` を追加。`addEvent` は所有者を `[自分, ...誘った人]` にして 1 件追加する（たろうがはなこを誘う → 所有者 [たろう, はなこ]。1 件の共有予定として両者のカレンダーに入る）。未登録メンバーを誘うと例外。自分自身が invited に入っていても重複しない。
  - `removeEvent(eventId)`：自分が所有者でなければ例外。所有者が自分だけなら予定を消し、共有なら自分だけ所有者から外す。
- `DayHud.tsx`：
  - 予定行の右端：自分の予定は「削除」（共有なら「抜ける」）、他の人の予定は「参加する」。
  - フォーム：種類は `<select>` から 8 種の建物チップ（`role="radiogroup"` / `aria-checked`）へ。「誘う：」に自分以外のメンバーのチェックボックス。送信ボタンの文言が「たろう・はなこ の予定を建てる」に変わる。送信後はタイトルと誘うをクリア（種類は保持）。
- `App.tsx`：`onAddEvent(title, category, invited)` と `onRemoveEvent={calendar.removeEvent}` を配線。
- CSS：`.category-picker` / `.category-btn(.is-selected)` / `.invite-row` / `.invite-option` / `.btn-danger:hover`。
- 動作確認：`tsc` / `oxlint` エラーなし。ブラウザで 12/31 を開き、「カウントダウン / 旅行 / 誘う：はなこ」で建てる → 一覧に「旅行 カウントダウン たろう・はなこ 抜ける」、3D は飛行機の足元にピンク＋青の 2 色台座。localStorage を読み、はなこを所有者に含む 12/31 の予定として保存されていることを確認。
- 未確認：「削除」「抜ける」の UI クリック（ユーザーのブラウザ操作と交錯するため）。`removeEvent` の分岐はコード上で確認。
