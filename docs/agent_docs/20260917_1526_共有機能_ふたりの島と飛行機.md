# カレンダー共有機能「ふたりの島」（案 E ベース → 橋を飛行機に変更）

## やったこと

- 共有機能の見せ方として案 E（海を挟んだ 2 つの島）を実装。当初は共通予定の日に「木の橋」を架けたが、人間の指示（15:26）で橋を廃止し、**共通予定の日に島と島を飛行機が往復する** 形に変更した。
- 新規ファイル：
  - `src/src/data/samplePartnerEvents.ts`：相方の固定サンプルデータ（シード 20260918、自分と山谷をずらした月別重み）。自分の予定（`sampleEvents`）から一部をコピーした「共通の予定」を含み、その日付集合を `partnerCommonDates` としてエクスポート。見せ場は 12/19（3 件）・10/10（2 件）・6/6（2 件）＋残りの各月は 10〜25 日で最初に予定がある日の先頭 2 件（毎月 1 便は飛ぶ）。
  - `src/src/components/month/Flight.tsx`：ボクセル飛行機（機首 +z）。2 次ベジェ軌道（頂点は同じ列の最大タワー高 +1.35）で塔の天面から天面へ往復し、両端で 0.8 秒待機。`lookAt` で進行方向へ機首を向け、後方にハートの旗（回転）を曳く。位相は日数 × 0.9 秒でずらす。
- 変更ファイル：
  - `data/sampleEvents.ts`：`TITLES` / `mulberry32` / `pick` を export（相方データで再利用）。
  - `lib/camera.ts`：`PARTNER_SEA_GAP`（2.6）、`partnerZOffset(rows)`、`monthSharedCameraPose(rows)`（両島が収まる高所俯瞰）を追加。
  - `components/month/MonthScene.tsx`：`shared` / `partnerByDate` / `commonDates` props を追加。相方の島（z オフセットした DayTower 群 + 日付ラベル、操作不可）、共通予定日の `Flight`、共有時の fog 拡大（26〜62）、影カメラ拡大（±15）、`maxDistance` 38。
  - `components/month/DayTower.tsx`：`onHover` / `onSelect` を省略可能にした（省略時はポインタイベントを付けない = 相方の島用）。
  - `components/hud/MonthHud.tsx`：「ふたりの島 / ひとりの島に戻る」トグルボタンとヒント文を追加。
  - `App.tsx`（共有ファイル）：`shared` state、相方データと共通日付の配線。
  - `styles/global.css`（共有ファイル）：`.hud-nav` を flex + gap に。
- 削除：`components/month/Bridge.tsx`（橋の実装。飛行機への変更に伴い削除）。
- 設計判断：共通予定の判定を「タイトル＋カテゴリ＋日付の一致」で行う案は、繁忙月で偶然の一致が多発して 12 月に橋（飛行機）が 6 本以上になったため廃止。固定データ側で意図的に用意した日付集合（`partnerCommonDates`）を直接使う方式にした。

## 動作確認（実行コマンドと結果）

- `cd src && npx tsc --noEmit -p tsconfig.app.json` → エラーなし。
- `cd src && npm run lint`（oxlint） → エラー・警告なし。
- `cd src && npm run build` → 成功（three.js 由来の 500 kB チャンク警告のみ。既存どおり）。
- `cd src && npm run dev -- --port 5173 --strictPort` → Cursor 内蔵ブラウザで確認：
  - 「ふたりの島」トグルで奥に相方の島が出現し、カメラが両島を収める位置へ補間移動。fog により奥の島に距離感が出る。
  - 12 月：12/19 の塔（自分・相方とも高い）間を飛行機が往復し、ハートの旗を曳く。海の上を通過する姿とタワー頂上での折り返しを目視確認。
  - 1 月（橋バージョン時に確認）：閑散月でも毎月 1 本の共通予定日が機能する。
  - 共有モードのまま 19 日をクリック → 日ビューへズームし、9 件の予定一覧が表示。「月に戻る」で復帰。
  - 「ひとりの島に戻る」でトグル解除、通常の月俯瞰カメラへ戻る。
  - ブラウザ操作ツールの ref クリックが古い要素に飛ぶ現象があり検証が乱れたが、座標クリックで再検証しアプリ側の問題ではないことを確認（`shared` は `App` の state で、ビュー遷移では変更しない）。
