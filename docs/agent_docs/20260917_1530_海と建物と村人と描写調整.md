# 海（谷）・建物 24 種・村人・ローポリ描写（リベース後の追加開発、サイクル 1）

Fable が設計・分担・監査を行い、実装は部下エージェント（Opus / Sonnet）に委譲した。

## やったこと

- **海＝谷**（`DayTower.tsx` / `Block.tsx` / `blockKinds.ts` / `MonthScene.tsx` / `DayHud.tsx` / `YearHeatmap.tsx` / `lib/camera.ts`）
  - 予定 0 の日は地面ブロックを置かず、半透明の水ブロック（上下に揺れる）にした。ホバー・クリックは水ブロックで受ける。
  - 地面ブロックの側面を砂浜色にし、島の縁に見せる。日付ラベルは海の日だけ水面に寝かせて表示。
  - ヒートマップの 0 件を海色に。日ビューの 0 件文言を海に合わせて変更。
  - `sampleEvents.ts`：通常日の約 2 割を予定 0 にして、12 月のような繁忙月にも海の日が出るようにした。
- **建物 24 種化**（`components/models/objects/**`）：各カテゴリに 2 種ずつ追加し、`index.ts` の対応表をラッパーにして屋上スロット位置からバリエーションを決定的に選ぶ（呼び出し側の型は不変）。
- **村人**（新規 `components/month/Villagers.tsx`、配線は `MonthScene.tsx`）：予定件数に応じて 1〜3 人、全体 60 人まで。屋上の外周を周回し、脚と腕を振る。1 つの `useFrame` で全員更新。
- **屋上のランダム配置**（`DayTower.tsx`）：3×3 スロットを日付シードで Fisher–Yates シャッフルし、±0.03 のずれを加える（バリエーション選択の `Math.round(pos/0.29)` を崩さない範囲）。
- **描写**（`MonthScene.tsx` / 新規 `Sea.tsx` / `global.css` / `Block.tsx` / `Voxel.tsx`）
  - 影を完全に無効化（Canvas の `shadows`、光源の castShadow、全 mesh の castShadow/receiveShadow）。
  - 環境光＋半球光＋直射 1 灯のローポリ風。露出 0.95、canvas に `contrast(0.94) saturate(0.92)`。
  - 海面：島周辺 24×24 を 64×64 分割し、サイン波 3 つの重ね合わせで頂点を毎フレーム更新（フラットシェーディング）。遠景は平板のまま。
  - チルトシフト風：Canvas の上に `backdrop-filter: blur` を mask で上下だけ効かせる div（ライブラリ追加なし）。
  - せり上がり中に日付ラベルと村人が浮く問題：`AfterRise` で 1.6 秒後に表示。
- **カメラ**（`lib/camera.ts`）：`monthCameraPose(rows, tops)` に変更し、全ブロックの高さ重心と最高塔から注視点と位置を算出。
- 依存の同期：採用版の lockfile に合わせ `npm install` を実行（oxlint が未インストールだったため）。新規ライブラリ追加はなし。
- `original_rule.md` に §11「時間切迫モード」を追加（ホスト指示）。

## 動作確認（実行コマンドと結果）

- `npx tsc --noEmit -p tsconfig.app.json` → エラー 0（各部下・統合後で確認）
- `npm run lint`（oxlint）→ エラー 0
- `npm run build` → 成功（chunk 500 kB 超の既知警告のみ）
- Chrome DevTools MCP でのスクリーンショット監査（Fable が目視）：
  - 12 月：海の日（9・15〜17・29・30）が青い水面になり、山と谷が同時に見える。屋上の建物が複数種類、村人が屋上にいる。
  - 8 月・9 月：海が多い島。波の面が見える。
  - 年ヒートマップ：0 件が海色。
  - 描写変更後：影が消えて柔らかい陰影。ただしカメラが急角度で近すぎ、上下ぼかしが主役の塔に掛かっていたため再調整中（別部下）。
- Console：赤エラー 0。three.js 側の既知 warn（`THREE.Clock` deprecated）のみ。
