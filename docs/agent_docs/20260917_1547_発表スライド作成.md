# 1 分発表用スライドの作成

## やったこと

- `docs/presentation/slides.html` を新規作成。人間から渡された情報（テーマ・一言コンセプト・驚きポイント・キャッチコピー・やりたかったこと）**のみ** を内容に使った 1 分想定・全 5 枚のスライド。
  - 構成：1. タイトル＋キャッチコピー → 2. コンセプト → 3. 驚きポイント＋キャッチコピー② → 4. やりたかったこと（ゲーム要素・自分の予定で村や街） → 5. 友人や恋人との予定＋カレンダー同期機能＋締めのキャッチコピー
  - デザインはアプリと同じ世界観：DotGothic16、インク `#1b2a41`、紙 `#fff8e7`、金 `#ffc83d`、空色グラデーション背景、下端に海の帯、タイトルにブロックタワー（草→土→石→雪→金の屋根）の CSS 装飾。パネルは 4px インク枠＋硬い落ち影。
  - 操作：クリック / → / Space / Enter で次へ、← で前へ。右下にページ番号（n / 5）。
- 単一 HTML・依存なし（フォントのみ Google Fonts。オフライン時はシステムフォントにフォールバック表示）。アプリ本体（`src/`）には一切手を入れていない。

## 動作確認（実行コマンドと結果）

- `cd docs/presentation && python3 -m http.server 8765` でサーバーを立て、Cursor 内蔵ブラウザで `http://localhost:8765/slides.html` を表示（内蔵ブラウザは file:// 直接オープン不可のため）。
- 全 5 枚をスクリーンショットで目視確認。→ キーでのページ送りとページカウンター（1/5→5/5）の更新を確認。
- 確認後、HTTP サーバーは停止済み。人間が見るときは `slides.html` を通常のブラウザ（Safari / Chrome）でダブルクリックで開けば動く（file:// で問題なし）。
