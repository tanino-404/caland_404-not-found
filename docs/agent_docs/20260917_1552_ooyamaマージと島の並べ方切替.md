# ooyama ブランチのマージと「島の並べ方」切替

## やったこと

- `origin/ooyama` をローカル `ooyama` として作成し、`main` にマージ（`--no-ff`）。
- ooyama の主旨：「ふたりの島」。自分の島の奥に海を挟んで相方の島を置き、共通の予定の日は塔と塔の間をハートの旗を曳く飛行機（`Flight.tsx`）が往復する。相方のデータは固定の `samplePartnerEvents.ts`。
- main の主旨：ログインと共有カレンダー（全員の予定を 1 つの島に建て、ホバーの台座で持ち主を見せる）。
- 人間の指示：**両方を再現するため、表示方法を切り替える仕組みにする。ログインは現行を流用。**

## 実装

- `types/calendar.ts`：`IslandLayout = 'merged' | 'split'`。
- `lib/members.ts`：`eventsOwnedBy(events, name)`、`datesSharedBetween(events, a, b)`。split の各島と飛行機の日付を、共有カレンダーの `owners` から導出する。固定の相方データ `samplePartnerEvents.ts` は削除（ログインユーザーで置き換わったため）。
- `lib/camera.ts`：ooyama の `partnerZOffset` / `PARTNER_SEA_GAP` はそのまま。`monthSharedCameraPose` は `monthSplitCameraPose(rows, tops)` にし、tanino 由来の「高い塔があるぶん引く」を加えた。
- `App.tsx`：`layout` と `partnerChoice` の state。`partner` は自分以外の先頭（選択があればそれ）。split のとき `islands = { mine, partner: { name, byDate, commonDates } }` を `useMemo` で作り `MonthScene` に渡す。メンバーが 1 人なら `partner === null` で split にならない。
- `MonthScene.tsx`：tanino 構成（`Sea` / `AfterRise` / `Villagers` / 海ラベル）をベースに、`partner` があれば奥の島（`DayTower` をハンドラなしで飾りとして描画、村人とラベルも）と `Flight` を追加。fog は ooyama の 2 段階（split は遠くまで）。`maxDistance` 38。グループの key に layout を含め、切替時にせり上がりをやり直す。
- `MonthHud.tsx`：右上に「ふたりの島で見る / ひとつの島で見る」（メンバー 2 人以上で有効。1 人なら disabled と title で理由）。split かつ他メンバーが 2 人以上なら凡例に「奥の島：」チップで相方を選ぶ。ヒント文はモードで変える。
- `DayTower.tsx`：ooyama の「`onHover` / `onSelect` を省略可（飾りの塔）」を採用。
- CSS：`.hud-nav` を折り返し可能にし `max-width: calc(100vw - 420px)`（ボタン 3 つで月タイトルに重なったため）。`.hud-partner`。
- `sampleEvents.ts`：ooyama が `TITLES` / `mulberry32` / `pick` を export していたのは相方データ用だったため、元の非公開に戻した。

## コンフリクト解消

- `App.tsx` / `MonthHud.tsx` / `MonthScene.tsx`：構造が違うため、上記の切替方式で書き直し。
- `sampleEvents.ts`：main の `SAMPLE_MEMBERS` / `SHARED_RATIO` / `pickOwners` を残す。
- `global.css`：`.hud-nav` は main の `align-items: stretch` を残す。

## 動作確認

- `tsc` / `oxlint` / `npm run build` すべて通過。
- ブラウザ：「ふたりの島で見る」→ 手前たろう・奥はなこの 2 島、共有予定の日に飛行機（12/19 など）。ヒント「手前が たろう、奥が はなこ の島…」。「ひとつの島で見る」→ 元の 1 島に戻る。右上のボタン列は折り返して月タイトルに重ならない。

## 未確認・懸念

- split で日をクリックしたときの日ビュー（カメラは自分の塔へ。HUD は全員の予定）は UI で未確認。
- 3 人以上のメンバーでの「奥の島：」チップは未確認（コード上のみ）。
