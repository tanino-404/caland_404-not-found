# 開発サーバー再起動（ERR_CONNECTION_REFUSED）

## やったこと

- Cursor 内蔵ブラウザのタブが `http://localhost:5173/` を開いており、Vite 開発サーバーはすべて aborted / 未起動だった。
- `cd src && npm run dev -- --port 5173 --strictPort --host 127.0.0.1` で再起動。
- 内蔵ブラウザと Mac の既定ブラウザの両方で `http://127.0.0.1:5173/` を開き、ログイン画面まで表示されることを確認。

## 動作確認（実行コマンドと結果）

- `lsof -nP -iTCP:5173 -sTCP:LISTEN` → 再起動前はリスナーなし。
- Vite ログ：`VITE v8.3.0 ready in 209 ms` / `Local: http://127.0.0.1:5173/`
- ブラウザ：タイトル「予定の混み具合マップ — 毎日が、村になる。」、ログイン画面（たろう / はなこ / 新しい名前）を確認。
