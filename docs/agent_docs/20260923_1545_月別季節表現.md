## やったこと

- `lib/season.ts`：1〜12 月ごとの季節ラベル・パーティクル種別・草/海/霧/空/ライト色を定義
- 3D：`SeasonAmbience`（島全体の雪・桜・雨・紅葉など）、`IslandSeasonDressing`（各マスの桜木・積雪・紅葉木など）、`SeasonContext` で `Block` の草色を月ごとに変更
- `MonthScene`：霧・ライト・海面色を季節連動。HUD に季節ラベル。`App` で `--sky-top` / `--sky-horizon` を月切替時に更新
- 年ビュー：島カードに季節ラベルと `yi-season-*` によるミニマップ背景のトーン変更

## 動作確認（実行コマンドと結果）
