# 開発サーバー再起動（ERR_CONNECTION_REFUSED）

## やったこと

- Vite 開発サーバーはすべて aborted で、ポート 5173 にリスナーがなかった。
- いったん `127.0.0.1` だけにバインドしたところ、`http://[::1]:5173/` は接続できなかった。ブラウザの `localhost` は IPv6 を先に見るため、`--host ::` で IPv4 / IPv6 の両方を受け付けるように再起動した。

## 動作確認（実行コマンドと結果）

- `lsof -nP -iTCP:5173 -sTCP:LISTEN` → `node` が `TCP *:5173` で LISTEN。
- `curl`：`127.0.0.1` / `[::1]` / `localhost` いずれも HTTP 200。
- Vite ログ：`VITE v8.3.0 ready in 131 ms` / `Local: http://localhost:5173/`
- 内蔵ブラウザで `http://127.0.0.1:5173/` と `http://localhost:5173/` を開き、タイトル「予定の混み具合マップ — 毎日が、村になる。」とログイン画面（たろう / はなこ）を確認。
