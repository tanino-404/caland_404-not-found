# 季節色の板が予定の建物を隠していた

## やったこと

- `IslandSeasonDressing` の `LandTopCap`（陸マスの天面全体を覆うピンク / 茶橙 / 白の板）を削除した。板は `towerTopY`、つまり予定の建物が並ぶ面に乗っていた。
- 桜・紅葉の木は陸マス（予定 1 件以上）の脇に残す。海マス・雨・快晴・雪は木を置かない。雪・紅葉・桜のパーティクルは `SeasonAmbience` のまま。

## 動作確認（実行コマンドと結果）

- `cd src && npx tsc --noEmit -p tsconfig.app.json && npx oxlint src/components/month/IslandSeasonDressing.tsx` → 成功
- ブラウザ：たろうでログイン。3月の屋上はピンクの板ではなく建物（仕事・飲食など）。2月は雪の粒子の下に建物。10月は紅葉の粒子の下に病院・飲食・仕事などの建物。海マスに木はない。
