# 天面の季節色と、空スロットの木

## やったこと

- 塔の天面を覆っていた季節色の板は置かない。`season.landTop` を最上段ブロックの天面マテリアルだけに使う（側面の標高色は維持）。
- 桜・紅葉・雪・雨・新緑・夏の木は、予定の建物が使っていない屋上スロット（幅 0.22 以内）に 1 本。9 件でスロットが埋まる日は木を置かない。海マスには置かない。

## 動作確認（実行コマンドと結果）

- `cd src && npx tsc --noEmit -p tsconfig.app.json && npx oxlint`（変更ファイル）→ 成功
- ブラウザ：3月は天面がピンクで、建物と桜の木が天面の上に並ぶ。10月は天面がオレンジで、病院・飲食などの建物と紅葉の木が被らずに見える。海マスは色も木もなし。

## 未完了・懸念

- 予定が 9 件の日は空スロットがないため木がない。
