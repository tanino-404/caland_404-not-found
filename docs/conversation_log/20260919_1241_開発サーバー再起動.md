### AI の応答

> `ERR_CONNECTION_REFUSED` の原因は、ブラウザが開いていた `http://localhost:5173/` に対して Vite の開発サーバーが止まっていたことです。起動して接続できるところまで確認しました。
>
> いま開く URL は **http://127.0.0.1:5173/** です。ログイン画面（「誰の地図に降りる？」）まで表示できています。既定のブラウザでも同じアドレスを開いてあります。
>
> サーバーはバックグラウンドで動かしたままです。止まったら、ターミナルで次を実行してください。
>
> ```bash
> cd src
> npm run dev -- --port 5173 --strictPort
> ```
>
> 発表スライド（`docs/presentation/slides.html`）はサーバー不要です。Finder からダブルクリックで開けます。
